# Third-party notices

This file will track bundled datasets and third-party components that require attribution.

## Planned offline place data

GeoNames is the preferred candidate for the first bundled postcode/city centroid dataset.

The dataset is not bundled in the repository yet. Before inclusion, KalPlan will record:
- exact download/source URL.
- snapshot date.
- checksum.
- exact license text applicable to that snapshot.
- required attribution.

No customer address data is sent to GeoNames for the offline estimate.
